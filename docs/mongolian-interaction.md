# 蒙古文输入与阅读交互

界面以中国境内规范传统蒙古文、内蒙古通行用法为语言基准。读者沿字列从上向下阅读，再向右进入下一列；输入、候选文字、选区、目录和检索结果需要遵循这一方向。

## 已采用的交互

- 搜索在专门的竖排编辑区中进行，文字及光标采用 `vertical-lr`，结果沿列向右展开。
- 输入法组合阶段保留候选文本，组合结束后再检索；原始输入保留变体选择符、元音分隔符和窄不换行空格。
- 输入法处理 Escape 时保留搜索窗口，使用原生文字控件处理选区和光标移动。
- 文章目录沿横向字列浏览，鼠标滚轮用于推进字列；触控板原生横向滚动和缩放手势保持其用途。
- 阅读区支持向左右滚动，以及按已经排出的字列边界使用 PageUp、PageDown 翻屏。
- 编年正文和人物简介按实际字列分页，底部显示位置及前后翻页按钮；缩放或窗口变化后重新对齐列边界。短屏为最长完整词保留高度，词尾与前词共同测量。
- 手机的年份目录收进横向目录面板，正文使用整个可用宽度。人物及来源从当前事件的固定入口打开。
- 人物详情与关系在同一面板内切换；沿关系浏览其他人物后可以逐步返回，关闭时焦点回到事件的人物入口。
- 双历详情保留竖排名称，年份及月日正向显示。320 像素宽度下日期按钮仍保留至少 44 像素点击宽度。
- 标题缩略只在完整词之间结束，窄不换行空格后的词尾随前词保留；单个长词完整显示。
- 字号入口采用蒙古文字母标记。

[W3C 蒙古文排版需求](https://www.w3.org/TR/mlreq/)是排版和控件方向的参考资料，语言词义与界面措辞另行核查。[Mongol 竖排控件项目](https://github.com/suragch/mongol)提供了原生竖排输入的交互参考。

## 文案核查

常用操作词集中于 `src/ui-copy.mjs`。构建过程从同一份文案产生组件库的辅助标签，与界面一同发布。

运行 `npm run audit:ui-copy` 生成 `docs/ui-copy-review.json`，列出各页面的 UI 文字、用途、同一概念的不同写法和核查状态。文章正文中的语法、专名和历史叙述需要另行逐条审阅。

目前记录了用户指出的 `ᠳᠣᠣᠭᠰᠢ`，已将“蒙古文书写”摘要和正文中的两处改为有用例支持的 `ᠳᠣᠷᠤᠭᠰᠢ`。主题入口与文章目录使用各自的名称。其余用词仍保留明确的待审状态。

语言验收覆盖词形、词义、格尾、词序、操作场景和页面上下文。代码检查覆盖输入文本保存、组合输入、字列方向、完整词截断、搜索焦点和内容更新。两类结果分别记录。

## v124 整词显示与更正

`shared/mongolian-orthography.mjs` 继承 main v124 的 11 项登记：8 个有来源的基础词、2 个已审核复合形式、1 个用户指定显示形式。显示层按完整词匹配，搜索将登记过的显示形式还原为规范拼写。FVS、MVS、ZWJ、ZWNJ 和 CGJ 在其他词中保留。

网页的 `Mn` 与原生 CoreText 共用这份登记。当前资料中的 120 处词级字段更正保存在 `word-corrections.json`，包含原文、更正结果和来源；此前已精简的说明保持现有表述。
