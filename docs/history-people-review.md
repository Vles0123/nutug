# 编年人物入口补充

核查日期：2026-10-09。原有32个人物、53条关系和18条首批事件均保留。本轮增加12个人物、2条有直接依据的关系及14条固定版本来源，形成 **44个人物、55条关系**。81条事件中，有人物入口的条目由37条增至54条；为17条事件补上21个人物链接。

各行只核查列明的事实。日期冲突保留在记录中，前端使用双方能够支持的年份或年代范围。传统蒙古文名字尽量复用现有内容；新简介与完整句法仍是独立语言编辑项目，机器与母语审校计数均未增加。
