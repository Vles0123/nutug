# 自定义皮肤

网页日历和 Apple 应用在外观设置中提供四种预设及个人皮肤管理。

1. 新建皮肤，输入名称，选择背景色、文字色和强调色。
2. 在预览中查看文字及选中日期的效果；保存后立即应用。
3. 已保存的皮肤可以切换、修改、导出或删除。取消编辑保留当前配色。
4. 将导出的 JSON 文件传到另一设备，在外观设置中导入。每次导入创建独立副本，保留原有皮肤。

网页使用浏览器本地存储；Apple 应用使用应用偏好存储。皮肤文件用于设备之间的手动交换。删除当前皮肤后应用明亮预设。

## 文件格式

```json
{
  "format": "nutug-theme",
  "version": 1,
  "id": "example-theme",
  "name": "ᠴᠠᠭᠠᠰᠤ",
  "colors": {
    "background": "#F3EAD8",
    "text": "#243746",
    "accent": "#8C3D26"
  }
}
```

文件使用 UTF-8，最大 64 KiB。颜色使用六位 RGB 十六进制值，导入时统一为大写。名称必填，最多 120 个 UTF-16 单元；ID 为 1–64 位英文字母、数字或连字符。导入后生成新的本地 ID。文件校验失败时保留已有配色和皮肤列表。

界面从三个颜色派生分隔线、次级文字与填充色，并根据背景明暗选择基础模式。选中日期及主要按钮的前景色由强调色自动决定。事件本身的颜色继续用于区分日程。

## 验证

`tests/custom-themes-check.cjs` 覆盖格式校验、编辑与持久化、重复导入、无效文件保留、删除及预设回退。原生渲染检查导入网页编码的同一份夹具、验证重新读取，并导出文件交给网页解析器检查。
