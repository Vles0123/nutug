# 日历与编年历史

Nutug 日历与 Nutug 历史分别提供独立网页包和 Apple 应用。两套应用共享传统蒙古文字体、界面组件及内容接口约定，分别管理自己的导航与偏好。

## 日历

日历首页处理日期与个人日程。提供年、月、周、日视图，今日、年月选择、日期深链、周首日选择、公历与农历显示。手机月历直接显示选中日期的日程，日期摘要可展开详情；搜索、新增保留在工具栏，导入、导出与皮肤放在设置中。

个人日程包括标题、地点、备注、全天或定时、跨日、日/周/月/年重复、间隔与结束日期。重复日程可修改整组或单次，也可删除单次或整组；删除后可撤销。网页数据保存在 localStorage，原生端保存到应用数据目录的 JSON 文件。保存失败保留原数据；读取失败时保留文件并显示错误。日期/时间输入接受蒙古文数字及常用分隔符，保存时转换成日期格式；正文与字形控制字符保持原样。错误定位到对应字段，保存后返回该日程的日期。

ICS 导入导出共用 ICAL.js。支持普通日程、全天日期区间、DAILY/WEEKLY/MONTHLY/YEARLY、INTERVAL、UNTIL、EXDATE、所附 VTIMEZONE 与 UTC 时间转换。复杂 BY* 规则、COUNT、RDATE 和 RECURRENCE-ID 目前会报告导入失败，整个导入保持原数据。当前日程为设备本地保存，跨设备交换通过 ICS 文件；通知提醒与账号同步尚未实现。

日期底座使用 `lunar-javascript` 1.7.7 的中国农历，范围 1901–2100，时区 Asia/Shanghai。网页与原生端使用同一日期引擎与测试向量。日历启动和日程管理均可离线工作。

四种皮肤为明亮、深色、纸面、黑白，同时保存字号、周首日和农历显示偏好。

## 编年历史与人物关系

此分支编辑源含 81 条事件，9 个时期、10 个地区标签，跨度为公元前 209 年至 2024 年；收录 44 个人物、55 条人物关系。内容是一套持续扩充的编年选读，尚未覆盖所有地区与人物。

事件按年份和时间范围排序，可在目录中选择时期、按年份或人物搜索、阅读原始来源；人物资料和关系从事件展开。缺少已核查人物节点的事件只展示正文与引用。

来源记录保存英文、西里尔蒙古语维基百科的页面与修订信息，逐项区分一致、差异和单侧覆盖；见 `history-source-review.json`。新增事件与人物的传统蒙古文稿见 `history-copy-draft.json`，Menksoft 核对状态单独记录在 `menksoft-review.json`。

历史经独立 JSON 接口发布，联网后比较版本号；下载失败时继续使用完整旧版缓存。当前 81 条事件、44 人物与 55 条关系已通过既有内容源发布。之后的编辑源更新仍需独立发布，客户端按版本下载。

## 共享实现

网页使用 React、React Aria Components、Motion、Lucide 与 D3。`shared/calendar-events.mjs` 同时服务网页和 JavaScriptCore 原生日程引擎。`interface-copy.json` 提供共用界面文案。

Apple 工程通过 `NutugCalendar` 与 `NutugHistory` 两个 target 构建 macOS、iPhone、iPad 应用。导航、月历、弹层、设置使用 SwiftUI；蒙古文由 CoreText 连写后按列旋转，编辑输入和可缩放关系图使用本地 WebKit。两个应用独立启动，日历启动不会初始化历史内容加载。

电子墨水屏继续使用按月发布的公历与农历 JSON 日期表及分段内容目录，主控型号待硬件选型确定。
