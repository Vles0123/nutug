# 日历与编年历史

Nutug 的主界面保留日历和历史两个入口。人物关系从历史事件进入。界面采用传统蒙古文竖排，共用文案用于网页和 Apple 原生应用。

## 共用底座

- 界面、字体、日期引擎随程序发布；历史资料通过独立的 JSON 内容接口更新。
- 更新只比较内容版本号，按普通路径下载 JSON。旧版资料在新版下载失败时继续可用。
- 日历首次启动就能计算日期。打开历史页时才读取资料，网页只取清单和核心历史数据。
- `shared/` 包含日期计算接口、记录引用和历史排序。`interface-copy.json` 将同一套界面文案提供给 SwiftUI。
- 电子墨水屏可读取按月发布的公历与农历日期表；主控型号仍由后续硬件选型确定。

## 日历

首页展示普通月历，每格同时显示公历日与农历日。支持今日、选日、前后月份、年份月份选择和日期深链。网页提供方向键、Page Up/Down、Home/End 操作；跨午夜时跟随今日，用户主动选中的其他日期保持不变。

日期底座继续使用 `lunar-javascript` 1.7.7 的中国农历计算，范围为 1901–2100。网页与原生端使用同一引擎与测试日期。现有鄂尔多斯等地区日期保留在内容源中，按对应地区与文献记录。

## 编年历史与人物关系

当前有 18 条事件，按年份与时间范围排列，保留时间不确定性。可前后阅读、按年份或人物搜索、打开来源。点击事件中的人物后，展示人物说明与相邻关系；关系图节点可以继续打开人物。

事件均有稳定 ID 和来源。维基百科来源保留原文标题、语言、页面 ID、修订 ID、访问日期和许可链接，正文使用传统蒙古文。早期年份与具体事实仍以条目所附来源为依据。母语编校记录见 `ui-copy-review.json`。

## Apple 原生端

Xcode 项目位于 `apple/`，面向 macOS、iPhone 和 iPad。导航、月历、年份选择、阅读、来源与人物面板由 SwiftUI 实现，交互关系图采用本地 WebKit 画布。历史资料缓存于应用数据目录，联网时检查版本。

蒙古文先以完整文本完成 CoreText 连写，再按列旋转排列，列序从左向右。程序包只携带界面、字体、日期引擎与第三方说明。构建与检查步骤见 [Apple 应用](apple-app.md)。
