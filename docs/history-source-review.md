# 编年与人物来源核查

核查日期：2026-10-07。覆盖当前产品使用的 **32 个人物、53 条关系、18 条编年事件**。核查逐项记录于 [history-source-review.json](history-source-review.json)。这里的“核心事实一致”仅指记录中列明的身份、亲属、年代、日期和事件；不同语言版本可能共用资料，不能据此宣称独立史学证明。

已修改：术赤卒年保留 1225 / 1227 两说；锁儿忽黑塔尼年代改为 12 世纪末至 1252；1368 年叙述改为妥懽帖睦尔离开大都北撤、在位至 1370，删除把全部地域统一写成同一统治终点的说法。为人物、事件与已对读关系接上英文/蒙古文条目，保留原有史籍与研究来源。

来源维护同时支持 en 和 mn，并固定到实际读取的 revision；运行来源更新命令不会自动把审阅版本换成较新文本。标题及前端摘要继续使用传统蒙古文，引用记录中的原题/语种是来源元数据。

## 来源差异与政治表述处理

- **窝阔台条目异常编辑**：mn 当前版本 872641 将其父亲改成不相符的名字。读取历史版本 **870229** 的原文后，确认父母与 1229 年即位段落正常；应用引用固定为该旧版。异常版本仅作审核记录，不作产品来源。
- **年月精度**：也速该卒年、诃额仑生卒、成吉思汗卒日、蒙哥生日/即位日、和世㻋即位/卒日、爱猷识理达腊生年在条目间或同一条目内有出入。产品保留原有世纪、年或范围精度，没有以资料框的一处数字替代争议。
- **真金太子册立**：英文写 1273，mn 写 1274。[《元史》卷 115 裕宗段](https://zh.wikisource.org/wiki/元史/卷115#裕宗)记至元十年二月立为皇太子，与 1273 一致，保留原文 1273。
- **脱列哥那摄政**：条目导言把 1241–1246 作为行政过渡期，资料框列正式摄政 1242–1246；未把宽泛区间升级为精确即位日期。
- **阿里不哥与忽必烈**：保留双方分别被推举、争位及 1264 年结束的事件叙述。蒙古文条目中对一方动机及唯一合法性的评判不移植为产品口吻。
- **元与北元**：使用当时政权、人物、城市及具体年份。元朝作为中国历史王朝与蒙古帝国分裂后的政权背景可以并列叙述；中世纪活动范围不能直接转换为现代国家主权主张。忽必烈实际控制范围与名义大汗地位分开理解，不复制“统辖全部汗国”的泛化。
- **别儿哥**：保持现有关系图没有“拔都直接传位别儿哥”的边；英语资料框包含中间继承者。蒙古文导言出现其亲赴艾因贾鲁特战役的说法，现有产品没有采用，继续不导入。
- **迈达里巴拉**：英文独立条目为 Maidilibala；mn 对应细节在爱猷识理达腊条目中。部分来源把他与额勒伯克相认，这仍是有争论的同一性判断；没有据此增加后代或合并人物。
- **洪武与北元往来**：保留史料所记书信与俘虏释放为 contact 类型，不改写成军事同盟或泛化的友好关系。1370 年具体书信仍需现有《明太祖实录》卷 57 支持。

## 尚需补齐

- 18 事件中 13 条的核心事实获得两种语言支持（其中 2 条记录差异）；4 条仅部分细节可对读，1 条具体书信仍依赖原始史料。逐项范围见上表，不能把“已查看”写成“全部事实通过”。
- 53 条关系逐条列在 JSON 中：49 条核心关系可对读，2 条时间/情节仍部分核验，2 条精确外交往来保留原始史料，未冒充双语维基核验完成。
- 传统蒙古文此次是事实修正与小幅措辞整理，尚未经内蒙古通行规范的母语编辑逐句审校。人物姓名变体、格尾与复杂重译仍需语言审校，不能由西里尔拼写直接推定。
- 旧文化资料库、部族长文及历法规则未纳入本轮，不能用当前覆盖率代表整个仓库内容质量。
