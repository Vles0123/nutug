## 使用方法

解压 ZIP，在解压目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:8000/ 。网页源码在 `dist/`，无需构建、后端或 API 密钥。完整说明见 ZIP 内的 `README.md`。

运行全部回归测试：

```sh
npm ci
npm test
```

测试依赖固定为 jsdom 30.1.1；Node.js 版本要求为 `^22.22.2 || ^24.15.0 || >=26.0.0`。此次导出在 Node.js 24.19.0 上运行全部 11 个回归脚本。依赖目录不包含在 ZIP 内。
