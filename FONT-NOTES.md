# Traditional Mongolian typography

Self-hosted Noto Sans Mongolian v3.002 (internal font version verified), SIL Open Font License 1.1. License bundled as dist/fonts/OFL.txt.
Official release: https://github.com/notofonts/mongolian/releases/tag/NotoSansMongolian-v3.002

Use writing-mode: vertical-lr and text-orientation: mixed, without per-letter rotation. Names are contiguous text in HTML inside SVG foreignObject. The graph edges remain SVG geometry. Bios and controls share the same font.
Reference: https://www.w3.org/International/articles/vertical-text/#mongolian

DOM interaction tests do not certify browser shaping or mobile touch rendering. Native-language proofreading is distinct from verifying historical facts and core name spellings.
